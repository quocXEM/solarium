# Solarium — design

## Why this game

- Tessera: too dry / board-game flat  
- Aureole: too shallow  
- Mothglass: too opaque  

Solarium = **physics merge** (proven addiction) + **luminous art** + **collection meta**.

## Loop

1. Aim & drop an orb  
2. Same tiers touch → merge up  
3. Fill toward the danger line  
4. Overflow → Again  
5. Discover higher tiers → album progress  

## Feel

Dark glass, soft glow, Cormorant type, quiet chrome, loud merge juice.
